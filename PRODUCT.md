# pg_local_cache website

The site helps PostgreSQL application developers decide whether explicit
primary-key row caching fits their workload, run the disposable demo, and
compare it with batched SQL. The documentation must describe the 2.0 contract
and keep executable examples aligned with the repository.

Use direct, technical English. Explain the operation and its limits; avoid
performance promises without recorded measurements, promotional filler, and
invented testimonials or adoption figures.

Keep the existing blue and lime palette. The user chose larger typography
and a clearer presentation inspired by the NestJS homepage. Diagrams should
explain read paths and transaction behavior. Keep motion short and optional.

The static Jekyll site must work without JavaScript, on narrow screens, with
keyboard navigation, in dark mode, and with reduced motion. Self-host assets.
The main actions are trying the local demo and reading benchmark methodology.
