A local row cache inside PostgreSQL

Read whole rows by primary key through one explicit SQL API. PostgreSQL remains authoritative and writes invalidate the cache transactionally.

Install → Technical reference → 
curl -fsSL https://github.com/profundium/pg_local_cache/releases/latest/download/install-latest.sh | bash -s -- app
psql │ postgres@localhost:5432/app
app=> SELECT local_cache.attach_table(
        'public.items'::regclass
      );

app=> SELECT local_cache.mget(
        'public.items'::regclass,
        ARRAY[42, 7, 42, NULL]::bigint[]
      );

 {"id":42,"value":"cached"}
 {"id":7,"value":"cached"}
 {"id":42,"value":"cached"}
 NULL
Explicit SQL API

One ordered local_cache.mget call.

Whole rows

Complete JSON rows keyed by the table primary key.

Transaction-aware

Writes fence affected entries before commit visibility.

Bounded memory

Shared-memory capacity is fixed at PostgreSQL startup.

Install on PostgreSQL 14–18

The bootstrap selects the matching glibc or musl binary, verifies release checksums, installs the extension, restarts through pg_ctl, and checks health.
