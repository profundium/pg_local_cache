PostgreSQL 14–18 · Linux amd64

pg_local_cache

Bounded, transaction-aware primary-key row cache. One SQL read API: local_cache.mget. Optional RESP2. Ordinary SQL stays ordinary.

Install

curl -fsSL https://github.com/profundium/pg_local_cache/releases/latest/download/install-latest.sh | bash -s -- app

Use

SELECT local_cache.attach_table('public.items'::regclass);

SELECT local_cache.mget(
  'public.items'::regclass,
  ARRAY[42, 7, 42, NULL]::bigint[]
);

Order, duplicates, and null positions are preserved. Writes use normal PostgreSQL DML and invalidate the cache transactionally.

Boundary

Built for repeated exact-primary-key reads whose hot set fits memory. It is not a join, range, aggregate, TTL, pub/sub, or distributed cache.
