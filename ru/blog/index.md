# Кэширование PostgreSQL на практике

Начните с работы, которую запрос повторяет. Эти статьи связывают путь чтения
PostgreSQL с решениями на уровне приложения: что измерять, как публикуются
устаревшие данные и что должен сохранять ответ пакетного чтения.

Впервые знакомитесь с расширением? Запустите [локальную демонстрацию](../docs/QUICKSTART.md),
затем воспользуйтесь [руководством по выбору кэширования](../docs/postgresql-caching.md),
чтобы выбрать путь чтения.
